วิธีใช้ Solo Smith

  1. ตั้ง key ของ backing track เลือกสเกล (pentatonic, blues, mode ต่างๆ) ใส่ BPM, จังหวะ และจำนวนห้อง
  2. ใส่คอร์ด (ไม่บังคับ) เช่น Am | F | C | G โซโลจะลงโน้ตในคอร์ดบนจังหวะหนัก ทำให้ฟังเข้ากับเพลง
  3. เลือกสไตล์ ความยาก และความหนาแน่นของโน้ต Box คือรูปสเกลในช่วง 4–5 เฟรต ส่วน 3 notes per string เหมาะกับการวิ่งโน้ตเร็ว
  4. กด Generate จะได้หลาย take ฟังพร้อมกลอง เบส และคีย์บอร์ด กด ↻ ที่วลีเพื่อสร้างใหม่เฉพาะวลีนั้น
  5. ส่งออก เป็น Guitar Pro (เปิดต่อใน Guitar Pro, TuxGuitar, MuseScore หรือส่งให้ Riff Forge), MIDI หรือ WAV เลือก Backing only เพื่อเอาวงไปซ้อมด้นสดเอง

ตัวเลขสีเขียวใน tab คือโน้ตในคอร์ด ณ จังหวะนั้น
